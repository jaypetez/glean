# aqua registry manifest

This manifest is ready to submit as a PR to [aquaproj/aqua-registry](https://github.com/aquaproj/aqua-registry).

Copy `pkg.yaml` to `pkgs/jaypetez/glean/pkg.yaml` in a fork of aqua-registry and submit a PR.

Once accepted, users can install via:
```bash
aqua g -i jaypetez/glean
```

This also enables `mise use aqua:jaypetez/glean` once a mise registry entry is added.
