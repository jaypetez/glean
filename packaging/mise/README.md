# mise registry entry

This entry is ready to submit as a PR to [jdx/mise](https://github.com/jdx/mise).

Copy `glean.toml` to `registry/glean.toml` in a fork of jdx/mise and submit a PR.

Requires the aqua-registry entry to be accepted first (for the `aqua:jaypetez/glean` backend).

Once accepted, users can install via:
```bash
mise use glean
```
